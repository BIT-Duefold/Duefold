# 桌面待办小组件

源码版运行 `npm run review`。首次默认显示；主窗口左下角“桌面小组件”是显示／隐藏开关：开启时再次点击即隐藏（包括边缘收起状态），隐藏时点击则显示并展开；按钮提示随状态变化，不弹出设置窗口。小组件右下角“显示＊条”菜单可选择最多显示 1 / 3 / 5 / 10 条（首次默认 5 条），选择后立即调整窗口大小，并记住条数；隐藏重开和退出重启都沿用上次选择。大头针控制是否固定。超过条数可滚动，少于条数自动缩短。无日期事项继续在主窗口“全部待办”查看。

小组件顶部可拖动，距显示器工作区边缘 24 DIP 内会吸附。未固定且鼠标离开 5 秒后以约 240 毫秒动画收成边缘条；鼠标进入边缘条附近 24 DIP 内以动画展开。大头针固定展开，左侧的“收起小组件”箭头会指向当前边缘（未吸附时指向最近边缘），点击可立即收起且保留固定偏好；鼠标离开提示条附近再移近即可展开。左右提示条约 10 DIP，上下可见提示条约 4 DIP。眼睛划线按钮隐藏。日期左右切换独立于主界面，点击日期打开小日历，可切换月份或选中某天，“今天”恢复跟随当天。条数菜单向下展开，小日历向日期按钮左下展开；两者均平滑渐显和缩放，关闭时也有短暂过渡，快速反向点击可衔接，遵循系统减少动态效果设置；通过预留透明画布保持待办主体的位置和尺寸，菜单、日历开关不调整原生窗口边界以避免闪烁，透明空白可穿透点击桌面；空间不足时调整弹层以完整可见，画布不覆盖保存的位置。今天始终单独位于下一天按钮右侧，选中今天时加粗；日期采用紧凑的“11月17日 · 周二”格式，日期与导航按钮宽度固定，连续切换不移动按钮。列表使用原标题，课程和平台另列标签；沿用课程可见性、有效截止时间及完成 / 忽略 / 平台提交判定。

关闭主窗口时，小组件保留最后一份快照并标注“主窗口已关闭”，点击条目重新创建主窗口并打开详情；后台同步与已连接平台仍随应用运行。隐藏小组件不影响已打开的主窗口。主窗口关闭后再隐藏小组件会退出应用；也可在主窗口“使用帮助”中点击“退出归序”。退出会销毁小组件，不产生另一个常驻应用。

## 实现边界

- 第二个 BrowserWindow 使用同一 Electron 主进程、preload、`load / onUpdate` 桥和页面构建入口；没有增加后台应用、依赖或运行时。
- 任务及同步协议不变。`widget.json` 单独保存本机窗口开关、条数、固定状态及展开时的 DIP 坐标和尺寸；日期为当前会话选择。收起状态不覆盖展开尺寸。窗口坐标无效、显示器移除或缩放变化导致越界时，回落到主屏右上角。
- 数据仅由主进程 `publish()` 推送；小组件不读写任务存储。鼠标位置检测与本地日期 / 阶段时钟不请求或轮询数据。主窗口关闭期间冻结最后一次推送的任务快照。
- 主进程按发送窗口区分权限。小组件仅能读取快照、调整本机展示条数和弹层、切换展示日期、固定、收起、隐藏和打开详情；保存任务、导入导出、平台操作、同步及全局设置仅接受主窗口调用。
- 无边框、透明窗口背景、禁止缩放 / 最大化、`focusable: false`、`skipTaskbar: true`；使用 `showInactive()` 和 `alwaysOnTop` 的 `floating` 层级。
- Windows 使用随源码提供的 Node-API 小模块检测前台窗口的客户区是否覆盖屏幕（区分普通最大化窗口，排除桌面与任务栏），全屏时暂时隐藏小组件，离开全屏后不抢焦点地恢复；检测间隔 200 毫秒。模块在既有主进程内直接调用 Windows `USER32 / KERNEL32`，不启动辅助进程，也不依赖额外运行时。`electron/native/fullscreen.c` 可通过 `npm run build:widget-native` 用 MinGW-w64 重建；交付已包含 Windows x64 的 `.node` 文件，打包时放在 asar 外。
