# 保存统一认证密码（可选）

延河与乐学共用**同一个北理统一认证身份**。归序默认只保存会话，不保存密码；勾选“保存密码”后，这个密码属于统一认证本身，而不是某一个平台。

> 这是可选项，默认关闭。不开启时行为与以前完全一致：能复用统一认证会话就自动换票，不能就提示“重新登录”。

## 使用

1. 打开“管理平台连接”，在页面顶部的**北京理工大学统一身份认证（延河 & 乐学）**一栏勾选“保存密码”；
2. 填写统一认证的学号/用户名与密码，点“保存”；
3. 保存后会立即尝试用这份凭据登录**所有已连接的校园平台**（延河、乐学），不需要再分别点开；
4. 取消勾选，或在对话框里点“清除”，即删除本机保存的密码。

## 生效范围

- **延河（`aita.yanhekt.cn`）**：已接入。令牌过期且 CAS 要求重新登录时，后台用保存的密码换票，再验证延河用户信息。
- **乐学（`lexue.bit.edu.cn`）**：已接入。乐学的教学会话是 Moodle 自己的 Cookie；检测到未登录时，会先用保存的密码登录乐学自己的 CAS service（`/login/index.php`），再跟随 ticket 回到乐学刷新 `MoodleSession`，然后继续读取。若统一认证要求短信或图形验证码，会停止并提示走官方窗口。

## 安全边界

- 密码只写入本机的系统加密库（Windows DPAPI，经 Electron `safeStorage`），与现有会话、同步密钥使用同一加密容器；`vault.json` 里只有密文容器。
- 密码不会进入渲染进程、待办快照、`settings.json`、导入导出备份或同步服务。
- 所有请求在主进程完成，复用延河自己的 Electron 会话与 Cookie，不外发到其他站点。
- 短信验证码与图形验证码**不会**被自动发送、识别或提交；检测到就直接停止并提示你到官方窗口完成，并暂停 30 分钟自动尝试，避免反复触发验证码。
- 连续 3 次密码被拒会自动停用（保留已保存的密码），之后需要你更新密码或重新登录。

## 已知限制

- 学校统一认证改版会导致页面解析失败：此时会提示“页面结构已变化，请在官方窗口登录”，不会误报成功。
- 启用短信二次验证的账号，多数情况下仍需人工输入验证码；本功能只能覆盖“仅密码”的情况。
- 乐学若改回本地登录表单（不再跳转统一认证），本功能不会使用密码，仍提示官方窗口登录。
- 密码变更后需要更新本机保存的密码，否则会连续失败并自动停用。
